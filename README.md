# My VIA Repository Fork for my qmk-based keyboard

![android-chrome-192x192](https://user-images.githubusercontent.com/1714072/222621960-ddfb8ee6-a486-4c66-8852-b204ba7c807b.png)

VIA is a powerful, open-source web-based interface for configuring your [QMK](https://qmk.fm)-powered mechanical keyboard. It allows you to customize your keymaps, create macros, and adjust RGB settings (if it has RGB) on the fly, without needing to recompile your keyboard's firmware. This makes keyboard customization easier and more accessible for everyone.

## Keyboard

This repository contains an additional keymap configuration I use for my Sharkoon Skiller SGK50 S3.

Feel free to use it as a base for your own config.

You can find my configuration directory [here](https://github.com/s3tupw1zard/qmk_via_SGK50_S3/tree/skiller_sgk50_s3/keyboards/sharkoon/skiller_sgk50_s3/keymaps/s3tupw1zard).
